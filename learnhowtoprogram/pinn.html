PINN: Physics-Informed Neural Network – Basic Example

1. Problem Definition

We want to solve a simple 1D Poisson equation:

u''(x) = -π² sin(πx), with u(0) = u(1) = 0

The analytical solution is: u(x) = sin(πx).

2. Neural Network Setup

import torch
import torch.nn as nn

class PINN(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(1, 20),
            nn.Tanh(),
            nn.Linear(20, 20),
            nn.Tanh(),
            nn.Linear(20, 1)
        )

    def forward(self, x):
        return self.net(x)

Explanation:

  • nn.Sequential: Constructs a 3-layer feedforward neural network.
  • Tanh(): Smooth nonlinear activations, ideal for PDEs due to their differentiability.
  • Linear: Fully connected layers with 1 input and 1 output.

3. Physics Loss Function

def physics_loss(model, x):
    x.requires_grad = True
    u = model(x)

    # Compute first derivative
    du_dx = torch.autograd.grad(u, x, grad_outputs=torch.ones_like(u), create_graph=True)[0]

    # Compute second derivative
    d2u_dx2 = torch.autograd.grad(du_dx, x, grad_outputs=torch.ones_like(du_dx), create_graph=True)[0]

    residual = d2u_dx2 + (torch.pi**2) * torch.sin(torch.pi * x)
    return torch.mean(residual**2)

Key lines:

  • requires_grad = True: Enables auto-differentiation on x.
  • autograd.grad(...): Calculates derivatives for PINN constraints.
  • residual: Measures how well the PDE is satisfied.

4. Boundary Condition Loss

def boundary_loss(model):
    x_left = torch.tensor([[0.0]], requires_grad=True)
    x_right = torch.tensor([[1.0]], requires_grad=True)
    u_left = model(x_left)
    u_right = model(x_right)
    return u_left.pow(2).mean() + u_right.pow(2).mean()

Explanation: This enforces u(0) = 0 and u(1) = 0 as soft constraints in the total loss.

5. Training the PINN

model = PINN()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# Collocation points
x_phys = torch.linspace(0, 1, 100).view(-1, 1)

for epoch in range(5000):
    optimizer.zero_grad()
    loss = physics_loss(model, x_phys) + boundary_loss(model)
    loss.backward()
    optimizer.step()

    if epoch % 500 == 0:
        print(f"Epoch {epoch}, Loss: {loss.item():.6f}")

Important lines:

  • torch.linspace(0, 1, 100): Generates 100 collocation points in the domain [0, 1].
  • loss.backward(): Computes gradients of both physics and boundary losses.
  • optimizer.step(): Updates the weights based on total loss.

6. Plotting the Result (Optional)

import matplotlib.pyplot as plt

x_test = torch.linspace(0, 1, 100).view(-1, 1)
u_pred = model(x_test).detach().numpy()
u_true = torch.sin(torch.pi * x_test).numpy()

plt.plot(x_test.numpy(), u_true, label="Exact")
plt.plot(x_test.numpy(), u_pred, '--', label="PINN")
plt.legend()
plt.title("PINN vs Exact Solution")
plt.show()

Explanation: This shows how close the learned solution is to the analytical result.
