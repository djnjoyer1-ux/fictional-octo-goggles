Introduction to Basic Python Operations

1. Variables and Data Types

In Python, you can store data in variables. Common data types include:

  • Integers (int): Whole numbers.
  • Floating Point Numbers (float): Decimal numbers.
  • Strings (str): Text data.
  • Booleans (bool): True or False values.

a = 10           # int
b = 3.14         # float
name = "Alice"   # string
is_active = True # boolean

2. Basic Arithmetic Operations

Python supports basic arithmetic operations:


x = 10
y = 5

addition = x + y      # 15
subtraction = x - y   # 5
multiplication = x * y  # 50
division = x / y      # 2.0 (returns a float)
integer_division = x // y  # 2 (returns an integer)
modulus = x % y        # 0 (remainder of division)
exponentiation = x ** y  # 100000

3. Conditional Statements

You can use if, elif, and else to check conditions:


age = 18

if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")

4. Loops

Python has two main types of loops: for and while.

For Loop:


for i in range(5):  # Will loop through 0, 1, 2, 3, 4
    print(i)

While Loop:


count = 0
while count < 5:
    print(count)
    count += 1

5. Functions

You can define reusable code blocks using def:


def greet(name):
    return "Hello, " + name + "!"

message = greet("Alice")
print(message)

6. Lists

Lists are ordered collections that can store multiple items:


fruits = ["apple", "banana", "cherry"]

# Accessing elements
print(fruits[0])  # apple

# Adding elements
fruits.append("orange")

# Iterating through a list
for fruit in fruits:
    print(fruit)

7. Dictionaries

Dictionaries store key-value pairs:


person = {"name": "Alice", "age": 25}

# Accessing values
print(person["name"])  # Alice

# Adding a new key-value pair
person["city"] = "New York"

8. Input and Output

You can take user input using input() and print using print():


name = input("Enter your name: ")
print("Hello, " + name + "!")
