Basic AI & Machine Learning Interview Questions – Explained

1. Sigmoid Activation Function

Interview Question: Implement the sigmoid function and its derivative.

import math

def sigmoid(x):
    return 1 / (1 + math.exp(-x))

def sigmoid_derivative(x):
    s = sigmoid(x)
    return s * (1 - s)

Explanation: Sigmoid squashes real values into (0,1). Its derivative s(1–s) is used in backprop.

2. Mean Squared Error Loss

Interview Question: Compute MSE and its gradient for predictions y_pred vs. true y_true.

def mse(y_true, y_pred):
    n = len(y_true)
    return sum((yt - yp)**2 for yt,yp in zip(y_true, y_pred)) / n

def mse_gradient(y_true, y_pred):
    n = len(y_true)
    return [(-2/n) * (yt - yp) for yt,yp in zip(y_true, y_pred)]

Explanation: MSE measures average squared error. Its gradient guides weight updates.

3. Gradient Descent Step

Interview Question: Perform one update step for weights w with gradient grad and learning rate lr.

def gradient_descent_step(w, grad, lr):
    return [wi - lr * gi for wi,gi in zip(w, grad)]

Explanation: Moves weights opposite to gradient to minimize loss.

4. Perceptron Prediction

Interview Question: Given weights w, bias b, and input x, return +1 or –1.

def perceptron_predict(w, b, x):
    activation = sum(wi*xi for wi,xi in zip(w,x)) + b
    return 1 if activation >= 0 else -1

Explanation: Basic linear classifier; decision boundary at activation=0.

5. Train Perceptron

Interview Question: One epoch of perceptron training.

def train_perceptron(X, y, w, b, lr):
    for xi, yi in zip(X, y):
        pred = perceptron_predict(w, b, xi)
        if pred != yi:
            # update rule
            w = [wi + lr * yi * xi_j for wi, xi_j in zip(w, xi)]
            b += lr * yi
    return w, b

Explanation: Adjusts weights on misclassification to move boundary.

6. Train/Test Split

Interview Question: Split dataset into train and test sets.

import random

def train_test_split(X, y, test_ratio=0.2):
    data = list(zip(X, y))
    random.shuffle(data)
    split = int(len(data)*(1-test_ratio))
    train = data[:split]
    test  = data[split:]
    X_train, y_train = zip(*train)
    X_test,  y_test  = zip(*test)
    return list(X_train), list(X_test), list(y_train), list(y_test)

Explanation: Shuffles and splits to evaluate generalization on unseen data.

7. Accuracy Metric

Interview Question: Compute classification accuracy.

def accuracy(y_true, y_pred):
    correct = sum(1 for yt,yp in zip(y_true, y_pred) if yt == yp)
    return correct / len(y_true)

Explanation: Fraction of correct predictions; simplest performance metric.

8. One-hot Encoding

Interview Question: Convert class labels into one-hot vectors.

def one_hot(labels, num_classes):
    result = []
    for lab in labels:
        vec = [0]*num_classes
        vec[lab] = 1
        result.append(vec)
    return result

Explanation: Transforms integer labels into binary vectors for multi-class models.

9. Shuffle Mini-batches

Interview Question: Generate mini-batches of size batch_size for SGD.

def get_mini_batches(X, y, batch_size):
    data = list(zip(X, y))
    random.shuffle(data)
    for i in range(0, len(data), batch_size):
        batch = data[i:i+batch_size]
        Xb, yb = zip(*batch)
        yield list(Xb), list(yb)

Explanation: Iterates shuffled subsets to update model in batches.

10. Early Stopping Criteria

Interview Question: Stop training when validation loss increases.

def should_stop(val_losses, patience=3):
    if len(val_losses) <= patience:
        return False
    # if no improvement in last 'patience' epochs
    return min(val_losses[-patience:]) >= min(val_losses[:-patience])

Explanation: Prevents overfitting by halting when validation loss stops improving.
