Python if __name__ == "__main__" Examples

1. unittest (Python Testing Framework)

if __name__ == "__main__":
    import unittest
    unittest.main()

Ensures tests run only when executed directly.

2. multiprocessing (Parallel Processing)

import multiprocessing

def worker():
    print("Worker process running")

if __name__ == "__main__":
    p = multiprocessing.Process(target=worker)
    p.start()
    p.join()

Prevents infinite recursion when using multiprocessing.

3. cProfile (Python Profiler)

if __name__ == "__main__":
    import cProfile
    cProfile.run("main()")

Profiles a Python program only when executed directly.

4. http.server (Built-in Web Server)

if __name__ == "__main__":
    from http.server import SimpleHTTPRequestHandler
    import socketserver

    PORT = 8000
    with socketserver.TCPServer(("", PORT), SimpleHTTPRequestHandler) as httpd:
        print(f"Serving at port {PORT}")
        httpd.serve_forever()

Starts a local web server only when run directly.

5. venv (Python Virtual Environments)

if __name__ == "__main__":
    import venv
    venv.create("my_env", with_pip=True)

Creates a virtual environment when executed directly.
