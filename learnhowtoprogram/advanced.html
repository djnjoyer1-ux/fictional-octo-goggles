Advanced Python Coding Questions – Explained

1. Matrix Multiplication (2×2)

Interview Question: Multiply two 2×2 matrices A and B, return the result matrix.

def mat_mul_2x2(A, B):
    # A and B are lists of lists: [[a,b],[c,d]]
    return [
        [A[0][0]*B[0][0] + A[0][1]*B[1][0],
         A[0][0]*B[0][1] + A[0][1]*B[1][1]],
        [A[1][0]*B[0][0] + A[1][1]*B[1][0],
         A[1][0]*B[0][1] + A[1][1]*B[1][1]]
    ]

Explanation: Standard definition: entry (i,j) is dot product of row i of A and column j of B.

2. Determinant of a 3×3 Matrix

Interview Question: Compute the determinant of a 3×3 matrix M.

def det_3x3(M):
    a,b,c = M[0]
    d,e,f = M[1]
    g,h,i = M[2]
    return (
        a*(e*i - f*h)
      - b*(d*i - f*g)
      + c*(d*h - e*g)
    )

Explanation: Expansion by the first row: +, –, + cofactors.

3. Solve Linear System Ax = b (2×2)

Interview Question: Given A (2×2) and b (2×1), solve for x using Cramer's Rule.

def solve_2x2(A, b):
    # A = [[a,b],[c,d]]; b = [e,f]
    detA = A[0][0]*A[1][1] - A[0][1]*A[1][0]
    if detA == 0:
        raise ValueError("Singular matrix")
    # Replace first column with b
    detX = b[0]*A[1][1] - A[0][1]*b[1]
    # Replace second column with b
    detY = A[0][0]*b[1] - b[0]*A[1][0]
    return [detX/detA, detY/detA]

Explanation: Cramer’s Rule: x = det(A₁)/det(A), y = det(A₂)/det(A).

4. Eigenvalues of a 2×2 Symmetric Matrix

Interview Question: Compute the two eigenvalues of a symmetric 2×2 matrix S.

import math

def eigvals_2x2_sym(S):
    # S = [[a,b],[b,d]]
    a, b = S[0]
    d = S[1][1]
    trace = a + d
    diff  = a - d
    disc  = math.sqrt(diff*diff + 4*b*b)
    λ1 = (trace + disc) / 2
    λ2 = (trace - disc) / 2
    return [λ1, λ2]

Explanation: Eigenvalues are roots of λ² – trace·λ + det = 0. Closed form uses trace and discriminant.

5. Numerical Integration: Trapezoidal Rule

Interview Question: Approximate ∫ₐᵇ f(x) dx with n equal subintervals.

def trapz(f, a, b, n):
    h = (b - a) / n
    total = 0.5*(f(a) + f(b))
    for k in range(1, n):
        total += f(a + k*h)
    return total * h

Explanation: Sum areas of trapezoids under f. Error decreases as 1/n².

6. Bisection Method for Root Finding

Interview Question: Find a root of continuous f on [a,b] using tol as tolerance.

def bisection(f, a, b, tol=1e-6):
    if f(a)*f(b) >= 0:
        raise ValueError("Root not bracketed")
    while (b - a)/2 > tol:
        c = (a + b) / 2
        if f(c) == 0:
            return c
        if f(a)*f(c) < 0:
            b = c
        else:
            a = c
    return (a + b) / 2

Explanation: Repeatedly halve interval where sign changes until width < tol.

7. Dot and Cross Product of 3D Vectors

Interview Question: Compute dot and cross products for u, v in ℝ³.

def dot(u, v):
    return sum(ui*vi for ui,vi in zip(u,v))

def cross(u, v):
    u1,u2,u3 = u
    v1,v2,v3 = v
    return [
        u2*v3 - u3*v2,
        u3*v1 - u1*v3,
        u1*v2 - u2*v1
    ]

Explanation: Dot = sum of componentwise products. Cross yields vector orthogonal to both.
