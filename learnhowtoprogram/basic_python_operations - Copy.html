Python Basic Data Types and Manipulation

1. Integers

In Python, integers are whole numbers (positive or negative) without a decimal point.

# Example of Integer
num = 10
print(num)
Output: 10

2. Floating Point

Floating-point numbers are numbers that have a decimal point.

# Example of Floating Point
pi = 3.14159
print(pi)
Output: 3.14159

3. Strings

Strings in Python are sequences of characters enclosed in single or double quotes.

# Example of String
greeting = "Hello, World!"
print(greeting)
Output: Hello, World!

4. Lists (Array)

In Python, lists are used to store multiple items in a single variable. They are similar to arrays in other languages.

# Example of List (Array)
fruits = ["apple", "banana", "cherry"]
print(fruits)
Output: ['apple', 'banana', 'cherry']

5. Booleans

Booleans represent the truth values True or False.

# Example of Boolean
is_raining = True
print(is_raining)
Output: True

6. Type Conversion

You can convert one data type to another in Python using functions like int(), float(), and str().

# Example of Type Conversion
num = "25"
converted_num = int(num)
print(converted_num)
Output: 25

7. Output Functions

In Python, the print() function is used to display data to the console. It's similar to console.log() in JavaScript.

# Example of Output
print("This is Python!")
Output: This is Python!

8. String Manipulation

Strings can be manipulated using various string methods, such as upper(), lower(), and replace().

# Example of String Manipulation
text = "hello"
print(text.upper())
Output: HELLO

9. Lists Manipulation

You can manipulate lists using methods like append(), remove(), and sort().

# Example of List Manipulation
fruits.append("orange")
print(fruits)
Output: ['apple', 'banana', 'cherry', 'orange']
