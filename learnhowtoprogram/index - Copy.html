Basic Python Coding Questions – Explained

1. Reverse a String

Interview Question: Write a Python function that reverses a string.

def reverse_string(s):
    return s[::-1]

Explanation: Python allows string slicing. s[::-1] starts from the end and moves backward, effectively reversing the string.

2. Check for Palindrome

Interview Question: Write a function to check if a string is a palindrome (same forward and backward).

def is_palindrome(s):
    return s == s[::-1]

Explanation: A palindrome reads the same backward. Using slicing again, we compare the string to its reverse.

3. Find Maximum in a List

Interview Question: Given a list of numbers, return the maximum value.

def find_max(lst):
    return max(lst)

Explanation: Python's built-in max() function efficiently finds the largest value in a list.

4. FizzBuzz (1–100)

Interview Question: Print numbers from 1 to 100. For multiples of 3, print "Fizz"; for 5, print "Buzz"; for both, print "FizzBuzz".

def fizzbuzz():
    for i in range(1, 101):
        if i % 15 == 0:
            print("FizzBuzz")
        elif i % 3 == 0:
            print("Fizz")
        elif i % 5 == 0:
            print("Buzz")
        else:
            print(i)

Explanation: Modulus checks determine divisibility. 15 is the least common multiple of 3 and 5.

5. Prime Number Check

Interview Question: Determine if a number is a prime.

def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

Explanation: Only check up to the square root of n for efficiency. If no divisor is found, it’s prime.

6. Factorial

Interview Question: Calculate the factorial of a number using recursion.

def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

Explanation: A classic recursive definition. Base case: 0! = 1. Recursive case: n! = n × (n-1)!

7. Find Duplicates in List

Interview Question: Given a list, return the duplicate elements.

def find_duplicates(lst):
    seen = set()
    duplicates = set()
    for num in lst:
        if num in seen:
            duplicates.add(num)
        else:
            seen.add(num)
    return list(duplicates)

Explanation: Use a set to track seen values and another to collect duplicates. Avoids repeated values.
