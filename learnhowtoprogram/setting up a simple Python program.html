Setting Up main() and Command-Line Arguments in Python

1. The main() Function in Python

Unlike some languages like C or Java, Python does not require a main() function to run a script. However, it's good practice to define one for better readability and maintainability.

Example of a Simple main() Function

# Simple main function in Python
def main():
    print("Hello from main!")

if __name__ == "__main__":
    main()

Why use if __name__ == "__main__"?

  • It ensures that the script runs only when executed directly, not when imported as a module.
  • Helps in organizing code better for larger projects.

2. Handling Command-Line Arguments Using sys.argv

Python provides the sys module to handle command-line arguments using sys.argv.

Example: Using sys.argv

import sys

def main():
    # sys.argv[0] is the script name, arguments start from index 1
    if len(sys.argv) > 1:
        print("Arguments received:", sys.argv[1:])
    else:
        print("No arguments provided.")

if __name__ == "__main__":
    main()

Running the Script:

python script.py arg1 arg2 arg3
Output:
Arguments received: ['arg1', 'arg2', 'arg3']

3. Using argparse for Better Argument Handling

The sys.argv method is simple but lacks flexibility. The argparse module is recommended for handling arguments in a structured way.

Example: Using argparse

import argparse

def main():
    parser = argparse.ArgumentParser(description="A simple Python script with arguments")
    parser.add_argument("name", type=str, help="Your name")
    parser.add_argument("--age", type=int, help="Your age", default=0)
    
    args = parser.parse_args()

    print(f"Hello, {args.name}!")
    if args.age > 0:
        print(f"You are {args.age} years old.")

if __name__ == "__main__":
    main()

Running the Script:

python script.py Alice --age 25
Output:
Hello, Alice!
You are 25 years old.

4. When to Use sys.argv vs. argparse

  • Use sys.argv when handling very simple arguments (e.g., one or two values).
  • Use argparse when dealing with multiple arguments, optional parameters, or help messages.

5. Conclusion

Now you know how to structure a Python program using main() and handle command-line arguments efficiently. Using if __name__ == "__main__" ensures that your script behaves predictably when executed directly.
