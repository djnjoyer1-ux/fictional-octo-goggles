Linear Algebra Cheat Sheet

Systems of Linear Equations: Gauss Elimination

Use row operations to transform a system into an upper triangular matrix, then solve by back-substitution. Watch out for pivot positions—they help determine rank and solution types.

Vectors, Angle, Dot Product, n-space

Dot product: \[ \mathbf{a} \cdot \mathbf{b} = |\mathbf{a}||\mathbf{b}|\cos(\theta) \] shows the angle between vectors. If \( \mathbf{a} \cdot \mathbf{b} = 0 \), the vectors are perpendicular.

Vector Space, Span, Subspace, Linear Dependence, Bases, Dimension

  • Vector Space: Closed under vector addition and scalar multiplication.
  • Span: The set of all linear combinations of a given set of vectors.
  • Subspace: Must contain the zero vector and be closed under addition and scalar multiplication.
  • Linear Independence: A set of vectors is independent if no vector can be written as a combination of others.
  • Basis: A minimal spanning set (independent and spans the space).
  • Dimension: The number of vectors in a basis.

Matrices, Transpose Matrix, Determinants

Transpose: Flip rows and columns (\(A^T\)). Determinant: If \(\det(A) \neq 0\), \(A\) is invertible. For a 2×2 matrix: \[ \det \begin{bmatrix} a & b \\ c & d \end{bmatrix} = ad - bc \]

Rank, Inverse Matrix, Cramer’s Rule, Change of Basis

Rank: Number of pivot positions, shows how many dimensions the space spans. Inverse: \( A^{-1} \) exists if \( \det(A) \neq 0 \). Cramer’s Rule: Solutions of \( A\mathbf{x}=\mathbf{b} \): \[ x_i = \frac{\det(A_i)}{\det(A)} \] where \( A_i \) is matrix \( A \) with the \( i \)-th column replaced by \( \mathbf{b} \).

The Eigenvalue Problem

Eigenvalues \( \lambda \) and eigenvectors \( \mathbf{v} \) satisfy: \[ A\mathbf{v} = \lambda\mathbf{v} \] Find eigenvalues by solving: \[ \det(A - \lambda I) = 0 \]

Final Tips for Test Night:

  • Understand the connection between span, rank, and independence.
  • Practice row reduction—it's everywhere.
  • For eigenvalues, always check the characteristic equation.
  • Sketch graphs for vector problems to visualize spans, bases, and subspaces.
