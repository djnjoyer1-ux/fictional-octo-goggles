Fluid Dynamics Applied to Cardiac Classifications (IBHRE / CCDS)

1. Core Concept: Cardiovascular System as a Fluid System

Heart = Pump, Blood = Fluid, Vessels = Pipes, Valves = Flow Control, Devices = Controllers

Fundamental Flow Equation:

\[ Q = \frac{\Delta P}{R} \]

  • Q = Cardiac output (flow)
  • ΔP = Pressure generated by heart
  • R = Vascular resistance

2. Hemodynamics & Pump Function

  • Heart acts as a pulsatile pump
  • Stroke Volume = volume per beat
  • Cardiac Output = flow rate
  • Compliance = vessel elasticity
  • Afterload = resistance

3. Flow Regimes & Turbulence

\[ Re = \frac{\rho v D}{\mu} \]

  • Low Re → Laminar flow
  • High Re → Turbulent flow
  • Turbulence → murmurs, inefficiency

4. Cardiac Classifications via Fluid Dynamics

Heart Failure

  • HFrEF: Pump failure → low ΔP → low Q
  • HFpEF: Stiff system → poor filling → high pressure, low compliance

Shock Types

  • Cardiogenic → pump failure
  • Hypovolemic → low volume
  • Distributive → low resistance
  • Obstructive → blocked flow

Valve Disease

  • Stenosis → velocity ↑ → turbulence
  • Regurgitation → backward flow

Arrhythmias

  • Irregular pulsatile input → unstable flow
  • Reduced filling → reduced output

5. NYHA Classes (I–IV) as Flow Capacity

Classification reflects ability to increase flow under demand.

ClassFluid InterpretationSystem Behavior
IFull flow reserveMeets all demand
IIMild limitationFails at high demand
IIISevere limitationFails at low demand
IVBaseline failureFails at rest

Critical Condition:

\[ Q_{available} < Q_{required} \]

6. Key Insight

All cardiac classifications can be reframed as failures of a fluid system:

  • Pump failure
  • Resistance mismatch
  • Flow instability
  • Boundary condition changes

Unifying Idea:

Electrical activity → Mechanical contraction → Fluid flow
